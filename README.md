# 💨 Hookah Mixology Library & Recipe Book

An interactive, dark-themed single-page web application designed for professional hookah lounge masters and tobacco enthusiasts. Contains a curated database of **100 premium tobacco mixes**, granular grammage calculators, strength indicators, and advanced liquid/fruit bowl craft instructions.

## 🌟 Key Features

- **100 Professional Mix Recipes:** Categorized across Medium (5-6/10), Strong (7-8/10), Extra Strong (9/10), and Overdose (10/10) strength profiles.
- **Brand & Line Precision:** Explicit tobacco brand, series, and line listings (e.g., *Tangiers Noir*, *Darkside Core/Rare*, *Element Earth/Fire*, *BlackBurn Shock*, *Satyr Platinum*, *Bonche 50*).
- **Interactive Bowl Grammage Calculator:** Dynamic auto-recalculation of component percentages based on custom bowl capacity presets (15g, 18g, 20g, 25g, 30g).
- **Liquid & Fruit Craft Extraction:** Expert notes on flavor extraction using custom base liquids (Oolong tea, espresso, grapefruit juice, essential oils) and fruit heads.
- **Dynamic Filtering & Search:** Search instantly by tobacco flavor, brand, bowl type, packing style, or strength rating.
- **Fully Responsive & Offline-Ready:** Ultra-fast, single-file (`index.html`) zero-dependency responsive UI optimized for mobile devices and desktop screens alike.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript:** High performance, no external framework dependencies.
- **Tailwind CSS (via CDN):** Clean, modern visual aesthetics with custom gold/dark color palettes.
- **Google Fonts:** Montserrat for modern typography.
